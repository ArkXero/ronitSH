# Civic Cycle

> Civic Cycle is a web application that provides open access to civic data for School Boards. It aims to empower residents, researchers, and policymakers by making it easy to explore and analyze local government data.

## What it is

> Civic Cycle is a web app built with Next.js and TypeScript, using PostgreSQL for data storage and Supabase for backend services. It provides an intuitive interface for users to access and analyze civic data related to School Boards in Fairfax County. The app includes features such as data visualization, search functionality, and user-friendly navigation to help users make informed decisions and engage with their local government.

## Why I built it

> I built Civic Cycle to promote transparency and civic engagement in my local community. By providing easy access to civic data, I hope to empower residents to stay informed about their local government and encourage active participation in civic affairs. Additionally, this project allowed me to apply my skills in web development and data management while contributing to a meaningful cause.

## Technical challenges

> One of the main technical challenges I faced while building Civic Cycle was designing an efficient database schema to handle the complex relationships between different types of civic data. I had to ensure that the database could support fast queries and provide a seamless user experience. Additionally, integrating Supabase for backend services required careful consideration of authentication and data security to protect user information.

## Lessons learned

> Through building Civic Cycle, I learned a lot about full-stack web development, including how to design and implement a scalable database schema, integrate third-party services like Supabase, and create an intuitive user interface. I also gained valuable experience in working with civic data and understanding the importance of data privacy and security in web applications. Overall, this project has been a rewarding learning experience that has helped me grow as a developer and contribute to my community.
